# UTF8 MARC21字节目录

leader为24字节，00-04记录长、09字符编码a、10指标长度2、11子字段代码长度2、12-16数据基址、20-23为4500。目录每项tag3字节、字段长度4位、起点5位；长度包含0x1e字段终止，目录末0x1e，记录末0x1d；数据区所有字段范围不重叠且完整覆盖。leader09非a明确不支持MARC-8，不自行转码。

001-009为控制字段，其他字段两个indicator后为子字段序列。子字段以0x1f加一字节ASCII代码开始，内容严格UTF8；field保留tag及目录次序，subfield保留代码及重复次序。$6普通字段形式880-NN[/script[/orientation]]，880字段形式TTT-NN[/script[/orientation]]，NN为两位occurrence；00表示未关联只留存。每个非00关系应在普通TTT及880间唯一双向匹配，缺失或多目标报关系冲突，但保留结构完整的原记录。

相同来源/001/005但字节不同是冲突，不覆盖；跨机构001相同不作实体合并。批清单声明记录数，末尾截断不能靠跳字节重同步。原始资料中245$a重复、245字段重复、中文UTF8偏移均有覆盖。初始工具仅核对源文件，不读取leader或关联880。
